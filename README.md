# TaskFlow — Personal Productivity Dashboard

A responsive task manager built with vanilla HTML, CSS and JavaScript.
 
## Features
- Create, edit, complete and delete tasks
- Due dates and priority levels
- Overview, Today, Upcoming and Completed views
- Search and sorting
- Progress statistics and completion ring
- Dark mode
- LocalStorage persistence (your tasks stay in this browser)

## Run locally
No installation or build step required. Open `index.html` in your browser.

## Project structure
- `index.html` — app structure.
- `style.css` — responsive UI and themes.
- `script.js` — task logic and LocalStorage.
